## **3. Регистрация домена (бесплатно на 30 дней)**  
🔹 **Сервис**: No-IP  
🔹 **Действия**:  
- Создал аккаунт  
- Выбрал бесплатный поддомен: **`steinteams.zapto.org`**  
- Установил **No-IP Dynamic Update Client (DUC)**  

⚠️ **Важно**:  
- Домен нужно подтверждать раз в 30 дней (придёт письмо)  
- No-IP автоматически обновляет IP при изменении  

---

## **4. Настройка XAMPP и размещение сайта**  
🔹 **Действия**:  
- Установил **XAMPP** (Apache + PHP)  
- Разместил файлы сайта в:  
C:\xampp\htdocs\
- Настроил виртуальный хост:  
```apache
<VirtualHost *:80>
    ServerName steinteams.zapto.org
    DocumentRoot "C:/xampp/htdocs"
    <Directory "C:/xampp/htdocs">
        Require all granted
    </Directory>
</VirtualHost>
```
- Добавил в файл hosts:
```
127.0.0.1 steinteams.zapto.org
```
- Проверка:
Сайт доступен по:

http://steinteams.zapto.org
